# myplanBYU — deploy repo

This repo is the **published site** for [myplan.jordanheaton.com](https://myplan.jordanheaton.com) — a degree-sequence optimizer for BYU students.

Do not edit here. The working tree lives in the Portfolio repo (`myplanBYU/`), and
`scraper/publish_site.ps1` mirrors the site files (and only the site files) into
this repo after each data refresh passes its sanity gate. Anything committed
directly here will be overwritten by the next mirror.

myplanBYU is an independent student project — not affiliated with BYU or MyMAP.
